A

Real video — your prompt actually makes the clip (Pollinations)

Replaces the fixed "Demo" sample with a real generator. Needs your Pollinations API key + a little credit.

Today: "Demo" always returns the same sample clip and ignores your prompt.
After: you add a Pollinations key in Settings (pay-as-you-go, a few cents per clip), pick a model (Seedance / Veo / Wan), and your prompt produces a real video. Demo stays as the free, no-key fallback.

⚙ One build choice — how the (slow) job runs

A-i · In-process MY REC for MVP

  • Already built; smallest change
  • Your browser polls until it's ready (works today)
  • If the server restarts mid-clip, that job is orphaned — I add a "stale job → failed after N min" safety net

A-ii · Background queue (BullMQ)

  • Survives restarts; auto-retries
  • Same pattern as the publish worker
  • More plumbing (a new queue + worker)
