Inboudly — Restructure Plan

From feature-sprawl → a focused, defensible product. Derived from the strategy interview + the verified deep-research report (2026-06-16).

The one-line thesis: A generation-first, bilingual (EN + 中文) content studio for SE-Asia SME owners & solo creators — that auto-posts to LinkedIn + Facebook, preps RedNote-native content for one-tap manual posting, and gets more “you” with every post (compounding brand memory — the thing no incumbent does).

3 · The moat — why it compounds (what Buffer/Jasper can't copy)

Incumbents store brand voice as a static file you edit by hand. Inboudly closes the loop:

📝 You publish a post → 📈 Inboudly reads its engagement → 🧠 Voice profile updates (Pinecone) → ✨ Next drafts sound more like you & lean to what worked ↺

The longer they use it, the better it gets and the more locked-in they are. That's the defensible edge the research validated as empty white space.

4 · The reality you must design around

🚨 RedNote has no compliant auto-post path for a Malaysia/Singapore company (verified against RedNote's own developer docs).

→ RedNote is content-prep, not auto-post. You generate native bilingual 笔记; the user posts it manually (one tap to copy). Still a real gap — Western tools ignore RedNote entirely.

→ Full automation stays on LinkedIn + Facebook, which have real APIs you've already built.
