🔧 Setup before manual testing

  1. Point the web app at the local API: set NEXT_PUBLIC_API_URL="http://localhost:3002" in .env (it currently points at your ngrok domain), then restart pnpm dev (Next bakes NEXT_PUBLIC_* at build).
  2. Have a Google Gemini API key ready (free tier: aistudio.google.com/apikey). Note: Gemini's free tier does NOT include image generation — image tests need paid billing enabled on the key's project.
  3. Have a Higgsfield key ready as api_key:api_key_secret from cloud.higgsfield.ai (with credit).
  4. Open http://localhost:3000 → log in → go to Dashboard → Settings.
