Facebook + LinkedIn connectors

two new connect rows · reuse the existing states ui-ux-pro-max

Adding two platforms is almost entirely backend (each a connector behind the proven seam). The only UI is two more rows in Settings → Social accounts, reusing the exact connect / connected / reconnect-needed states already built. Brand colour lives on the icon chip only; everything else matches the existing rows. No per-post controls for v1 (LinkedIn posts default to PUBLIC).

Design notes (ui-ux-pro-max)

  • consistency Facebook + LinkedIn are just two more entries in the same connect list — identical row layout, button styling, and the three shared states (connected / reconnect-needed / not-connected). No new component; they slot in like YouTube did.
  • brand · icon-only Brand colour is confined to the 36px icon chip (Facebook #1877F2, LinkedIn #0A66C2; lightened in dark mode for contrast) — never a large fill, so text/contrast stay neutral and accessible. Uses the lucide Facebook / Linkedin glyphs to match the app's icon set.
  • a11y Each Connect button has an explicit aria-label="Connect Facebook/LinkedIn" (the visible "Connect" is generic); status is icon + text, never colour alone; ≥38–40px targets + focus rings (inherited).
  • YAGNI · no per-post UI v1 adds no per-post controls. Facebook posts to the connected Page; LinkedIn posts PUBLIC by default. (A LinkedIn visibility selector or FB Page picker can come later if needed — they'd reuse the YouTube per-post pattern.)
  • inherited free Connect → OAuth popup, connected ✓, reconnect-needed (token-refresh), and the Composer's "connect in Settings" advisory all work for the new platforms with zero extra UI — they ride the generic flow.
