Design notes (ui-ux-pro-max)

  • export · one control, 4 states The Export button morphs idle → exporting (spinner, disabled) → ready (Download) → failed (recoverable) in place — no layout jump; status is icon+text, polling mirrors the existing Generations tray.
  • charts Line chart has a legend + tooltip + accessible distinct colours (not red/green-only), tabular figures in the table, and a real empty state instead of a blank axis frame; respects reduced-motion.
  • error-recovery A failed export states the cause + offers "Try again"; analytics refresh is explicit + toasts ("check back shortly") so the async pull isn't mistaken for instant.
  • consistency Pinterest reuses the exact connect-row pattern + 3 states; brand red on the icon chip only; aria-label on Connect.
  • parked, not broken Live platform metrics + Pinterest OAuth are parked; the UIs degrade to clear empty/not-connected states rather than errors.
