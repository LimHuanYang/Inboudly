Full vision (roadmap — Plans 2 & 3)
  • Composer media toggle — a [ Image | Video ] segmented switch in the "Generate with AI" card; the prompt stays shared, controls swap per mode.
  • Video controls — prompt, duration (provider-dependent, e.g. 4s/8s), aspect ratio, in-Composer provider + model picker, and an optional "Animate an image" reference.
  • Async progress — inline "Rendering… ~2 min" bar with Cancel; navigate away and the job continues, announced by a toast + tray badge on completion.
  • Result handling — finished clip attaches to the post draft (click-to-attach, like images) and auto-saves to the media library.
  • Generations tray — header Activity button + count badge; rows show status (rendering / ready / failed) with Cancel / View / Attach / Retry actions.
  • Settings → AI defaults — a third "Video generation" block (Provider + Model), matching Caption and Image; paid providers disabled until their key is saved.
  • Faceless per-scene — each scene gets a Still | AI clip | Upload source picker, plus a project-level Generate all clips.
  • Media library — in-flight renders appear as shimmer placeholders that resolve into the real clip (no layout shift).
v1 scope notes:
  • Cost line shows time-only ETAs (e.g. "~90s") — no dollar figures in v1.
  • Clips are short (≈4–10s per provider); long narratives come from stitching Faceless scenes.
  • Free Pollinations is the keyless default — works with no key, like image gen.
