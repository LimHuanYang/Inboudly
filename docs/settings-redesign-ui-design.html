Design notes (ui-ux-pro-max)

  • nav-hierarchy A left section rail replaces the 4-card scroll — Workspace / Social / AI providers / AI defaults / Billing are scannable + jumpable. On ≥1024px it's a sidebar; under 680px it collapses to a top tab strip (adaptive-navigation).
  • consistency · state-clarity Social accounts = one row per platform, grouped Connected → Needs-attention → Available, each with exactly one action (Disconnect / Reconnect / Connect). Kills the old list-plus-7-buttons redundancy; the reconnect-needed amber state stays consistent with the token-refresh design.
  • progressive-disclosure AI-key providers collapse to a one-line summary (category tag + Configured ····key / Not configured); click to expand the key + model + Test/Clear. Five always-open forms → a calm list you scan in seconds.
  • flow Order is now providers → defaults conceptually (keys exist before you pick which runs each task); the "no key" options stay disabled with a reason instead of silently failing.
  • brand · icon-only Platform brand colour lives only on the 38px icon chip; provider rows stay neutral. Status is icon+text+colour, never colour alone (color-not-only), with aria-labels on every action.
  • consistency · components Implementation swaps the ad-hoc <input>/<select> for the app's shadcn Input/Select so focus rings, dark mode, and spacing match the rest of the dashboard.
